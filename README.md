# Каталог персонажей Rick and Morty

Небольшое Flutter-приложение с каталогом, поиском по имени и карточкой персонажа. Данные приходят из [Rick and Morty API](https://rickandmortyapi.com/documentation).

## Запуск

Требуется Flutter с Dart 3.12 или новее. Из корня проекта:

```sh
flutter pub get
flutter run
```

Для проверок:

```sh
dart format lib test
flutter analyze
flutter test
```

## Устройство проекта

- `lib/app` — тема и базовый URL API;
- `lib/domain` — модель персонажа и контракт постраничного репозитория;
- `lib/data` — REST-запросы через Dio и разбор JSON;
- `lib/presentation` — Riverpod-состояние, каталог и экран деталей.

Поиск отправляется через 350 мс после последнего изменения. Ответы устаревших запросов игнорируются. Ошибку загрузки страницы можно повторить, не теряя уже загруженный список. При переходе в детали каталог остаётся открытым под ним, поэтому запрос, результаты и прокрутка сохраняются.
